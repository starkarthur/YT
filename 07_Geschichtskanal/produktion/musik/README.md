# Musik-Bibliothek

Hier liegen lizenzierte Musikstücke (MP3), die die Pipeline unter die Stimme legt. Der Produktionsplan nennt den Dateinamen im Feld `musik`. Fehlt die Datei, wird der Short ohne Musik geschnitten.

Pro Stück in `lizenzen.md`: Datei, Quelle/Dienst, Lizenz, Datum, Nachweis. Nur Musik mit kommerzieller Nutzung auf YouTube, TikTok und Instagram. Keine bekannten Lieder (Content-ID-Ansprüche).

Benötigte Stimmungen für den Start: Spannung (1920er/Jazz), episch/dramatisch (Naturkatastrophen), kurios/verspielt, ruhig/staunend.
