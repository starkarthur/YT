# History Shorts – Produktions-Worker

Automatische Produktion englischer Geschichts-Shorts (KI-Bilder, KI-Video, KI-Stimme, Schnitt) mit GitHub Actions.

- `main`: Code (`07_Geschichtskanal/produktion/`, `.github/workflows/`). Geschützt, Änderungen nur per Pull Request.
- `inhalt`: Skripte, Produktionspläne, Texte und Prüfberichte.
- `buecher`: Kosten- und Veröffentlichungsprotokoll (schreibt nur der Workflow).

Schlüssel liegen ausschließlich als verschlüsselte GitHub-Secrets in den Umgebungen, nie im Code.
Alle Szenen sind KI-generierte, nachgestellte Darstellungen und werden auf den Plattformen so gekennzeichnet.
